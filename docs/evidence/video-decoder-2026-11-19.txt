== 2c. Codec facts
* c2.goldfish.hevc.decoder advertises Main and MainStill only (dumpsys media.player); a Main10 / HLG / PQ clip
  fails in the guest helper: "GoldfishHevcHelper: error in decodeHeader: 0x43dd" -> MediaCodec err 0xe -> player error
  (not green). VP9 profile 2 (10-bit) plays on c2.goldfish.vp9.decoder.
* flush() right after start() drops the codec-specific data given to configure(); without resubmitting it the
  H.264 decoder never outputs a frame (black, not green). TikTok's log shows output after its early flush, so it
  resubmits; CodecActivity now does too.
* ANDROID_EMU_MEDIA_DECODER_VTB (36.4.9, disassembly of MediaH264DecoderGeneric/MediaHevcDecoderGeneric::init*):
  only the exact value "0" skips VideoToolbox (ffmpeg path); unset or anything else = VideoToolbox.
* Per codec: -append-userspace-opt androidboot.qemu.hwcodec.hevcdec=0 replaces the engine's hevcdec=2 on the kernel
  command line (ro.boot.qemu.hwcodec.hevcdec=0, avcdec/vpxdec stay 2): HEVC then uses c2.android.hevc.decoder,
  H.264 stays c2.goldfish.h264.decoder. Verified once by a direct engine launch (cold boot). Not offered as a mode.
